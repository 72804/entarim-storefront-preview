# Entarim product page previews

## Install

```bash
npm install
```

## Run

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Deploy to Vercel

```bash
npx vercel
```

Or import the Git repository in the Vercel dashboard. Framework preset: Next.js.

## Preview routes

- `/p/entarim-classic-8f31c2` — ENTARIM+ (current design + new features)
- `/p/entarim-editorial-4d72ab` — ENTARIM Editorial (premium redesign)

The root `/` page is an internal selector only.
